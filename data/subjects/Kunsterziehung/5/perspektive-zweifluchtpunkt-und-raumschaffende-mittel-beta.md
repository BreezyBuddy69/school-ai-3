## Zweifluchtpunktperspektive (Eckperspektive)

Bei der **Zweifluchtpunktperspektive** wird ein Objekt (z. B. ein Gebäude) so dargestellt, dass man **eine Ecke** frontal sieht — die beiden sichtbaren Seitenflächen fluchten dann jeweils zu einem **eigenen Fluchtpunkt**, beide liegen auf derselben Horizontlinie.

| Merkmal | Zentralperspektive (1 Fluchtpunkt) | Zweifluchtpunktperspektive (2 Fluchtpunkte) |
|---|---|---|
| Blickwinkel | frontal auf eine Fläche | auf eine Gebäude-/Objektecke |
| Fluchtpunkte | 1, mittig auf der Horizontlinie | 2, meist links und rechts ausserhalb des Objekts auf der Horizontlinie |
| Wirkung | ruhig, symmetrisch | dynamischer, räumlich „greifbarer" |

> Merke: Beide Fluchtpunkte der Zweifluchtpunktperspektive liegen immer auf **derselben Horizontlinie** — nur ihre Position links/rechts unterscheidet sich je nach Blickwinkel auf das Objekt.

## Raumschaffende Mittel

Neben der linearen Perspektive (Fluchtpunkte) gibt es weitere zeichnerische Mittel, um auf einer Fläche **Räumlichkeit und Tiefe** zu erzeugen:

| Mittel | Wirkung |
|---|---|
| **Überschneidung** | Ein Objekt verdeckt teilweise ein anderes → das verdeckte Objekt wirkt weiter entfernt |
| **Grössenunterschied/Staffelung** | Näher liegende Objekte werden grösser, weiter entfernte kleiner dargestellt |
| **Standlinie (Tiefenlage)** | Objekte, die weiter oben im Bild stehen, wirken (bei Aufsicht auf eine Fläche) weiter entfernt |
| **Luftperspektive (Farbperspektive)** | Entfernte Objekte werden blasser, kontrastärmer und oft bläulicher dargestellt — entspricht der Wahrnehmung durch die dazwischenliegende Luftschicht |
| **Licht-Schatten-Modellierung** | Helligkeitsverläufe (Licht, Schatten, Schlagschatten) erzeugen den Eindruck von Volumen und Raumtiefe |
| **Schärfe/Unschärfe** | Scharf gezeichnete Objekte wirken näher, unscharfe/verschwommene wirken weiter entfernt |

> Achtung Prüfung: Raumschaffende Mittel wirken auch **ohne** perspektivische Konstruktion (Fluchtpunkte) — sie werden oft kombiniert eingesetzt, etwa Überschneidung **und** Grössenstaffelung **und** Luftperspektive im selben Bild.

## Zusammenspiel in der Bildkomposition

In einer gelungenen räumlichen Darstellung wirken meist **mehrere raumschaffende Mittel gleichzeitig**: Die lineare Perspektive gibt die geometrische Struktur vor (Fluchtpunkte, Horizont), während Überschneidung, Staffelung, Luftperspektive und Licht/Schatten die Raumwirkung zusätzlich verstärken und „weicher" erscheinen lassen.
