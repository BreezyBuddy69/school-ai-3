# Zweiter Weltkrieg (1939–1945)

## Ursachen
- **Versailles-Vertrag (1919)** — Demütigung Deutschlands, Kriegsschuld, Reparationen
- **Weltwirtschaftskrise (1929)** — Massenarbeitslosigkeit, sozialer Druck
- **Aufstieg des Nationalsozialismus** — Hitler 1933 Reichskanzler
- **Appeasement-Politik** — Brit./Franz. tolerierten Hitlers Expansion

## Wichtige Daten
| Datum | Ereignis |
|-------|---------|
| 1.9.1939 | Überfall auf Polen → Kriegsbeginn |
| 1940 | Fall Frankreichs, Luftschlacht um England |
| 22.6.1941 | Überfall auf die Sowjetunion (Unternehmen Barbarossa) |
| 7.12.1941 | Japan greift Pearl Harbor an → USA tritt bei |
| Feb. 1943 | Niederlage Stalingrad — Wendepunkt Ostfront |
| 6.6.1944 | D-Day: Alliierte landen in der Normandie |
| 8.5.1945 | Kapitulation Deutschlands (VE-Day) |
| 6./9.8.1945 | Atombombe Hiroshima/Nagasaki |
| 2.9.1945 | Kapitulation Japans → Kriegsende |

## Holocaust
- Systematische Vernichtung von ~6 Mio. Juden
- Wannsee-Konferenz 1942 → "Endlösung der Judenfrage"
- Vernichtungslager: Auschwitz, Treblinka, Sobibor u.a.
- Insgesamt ~70 Mio. Tote im gesamten Krieg

## Kriegsverläufe
### Ostfront
- Grösster Landkrieg der Geschichte
- Unternehmen Barbarossa → zunächst Erfolge
- Winter 1941/42 → Scheitern vor Moskau
- Stalingrad (1942/43) → Wendepunkt, 300.000 dt. Soldaten eingekesselt

### Westfront / Nordafrika
- Rommel in Nordafrika ("Wüstenfuchs")
- Alliierte Landung in Sizilien 1943
- D-Day Juni 1944 → Westlich eingekreist

## Folgen
- ~70 Mio. Tote weltweit
- Europa zerstört, Deutschland geteilt
- Nürnberger Prozesse (1945–46)
- Gründung der UNO 1945
- Beginn des Kalten Krieges
- Gründung Israels 1948
