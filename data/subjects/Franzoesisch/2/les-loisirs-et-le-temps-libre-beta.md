## 1. Aimer / adorer / détester + infinitif

| Konstruktion | Beispiel |
|---|---|
| **j'adore** + Infinitiv | J'**adore** lire. |
| **j'aime** + Infinitiv | J'**aime** nager. |
| **je préfère** + Infinitiv | Je **préfère** jouer au foot. |
| **je n'aime pas** + Infinitiv | Je **n'aime pas** courir. |
| **je déteste** + Infinitiv | Je **déteste** ranger ma chambre. |

## 2. Jouer à / jouer de

| Regel | Beispiel |
|---|---|
| **jouer à** + Sport/Spiel | jouer **au** foot, jouer **aux** échecs |
| **jouer de** + Musikinstrument | jouer **du** piano, jouer **de la** guitare |

> Achtung Prüfung: **à** und **de** verschmelzen mit dem bestimmten Artikel: à + le = **au**, à + les = **aux**; de + le = **du**, de + la bleibt **de la**. Häufiger Fehler: *jouer au piano* statt richtig *jouer **du** piano*.

## 3. Faire du / de la / de l' + activité

| Aktivität | Beispiel |
|---|---|
| **faire du** (m.) | faire **du** vélo, faire **du** ski |
| **faire de la** (f.) | faire **de la** natation, faire **de la** randonnée |
| **faire de l'** (Vokal) | faire **de l'**équitation |
