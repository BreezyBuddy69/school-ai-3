## 1. L'heure — die Uhrzeit

**Quelle heure est-il?** (Wie spät ist es?) → **Il est ...**

| Uhrzeit | Französisch |
|---|---|
| 1:00 | Il est une heure. |
| 3:00 | Il est trois heures. |
| 3:15 | Il est trois heures **et quart**. |
| 3:30 | Il est trois heures **et demie**. |
| 3:45 | Il est **quatre heures moins le quart**. |
| 3:10 | Il est trois heures **dix**. |
| 3:50 | Il est **quatre heures moins dix**. |
| 12:00 (Mittag) | Il est **midi**. |
| 00:00 | Il est **minuit**. |

> Merke: Bei Bedarf präzisiert man mit **du matin** (morgens), **de l'après-midi** (nachmittags), **du soir** (abends): *Il est huit heures du soir.*

## 2. L'impératif — die Befehlsform

Gebildet aus der **présent**-Form von tu/nous/vous — **ohne** Subjektpronomen.

| Infinitif | (tu) | (nous) | (vous) |
|---|---|---|---|
| parler | **Parle !** | Parlons ! | Parlez ! |
| finir | Finis ! | Finissons ! | Finissez ! |
| aller | Va ! | Allons ! | Allez ! |
| être | Sois ! | Soyons ! | Soyez ! |
| avoir | Aie ! | Ayons ! | Ayez ! |

**Négation:** Ne-Konstruktion umschliesst den Befehl: **Ne parle pas !** / **Ne sois pas** en retard !

> Achtung Prüfung: Bei **-ER-Verben** (und *aller*) fällt das **-s** der tu-Form im Imperativ weg: *tu parles* → **Parle !** (nicht *Parles!*). Ausnahme: **vor y/en bleibt das -s** (Verbindungs-s): **Vas-y !** (Geh hin!), **Manges-en !** (Iss davon!).

## 3. Les prépositions de lieu — Ortspräpositionen

| Präposition | Bedeutung | Beispiel |
|---|---|---|
| dans | in | Le chat est **dans** la maison. |
| sur | auf | Le livre est **sur** la table. |
| sous | unter | Le sac est **sous** la chaise. |
| devant | vor | Il attend **devant** l'école. |
| derrière | hinter | Le jardin est **derrière** la maison. |
| entre | zwischen | La cuisine est **entre** le salon et la chambre. |
| à côté de | neben | La banque est **à côté de** la gare. |
| en face de | gegenüber von | Le supermarché est **en face de** l'école. |
| près de | in der Nähe von | J'habite **près de** Vaduz. |
| loin de | weit weg von | Il habite **loin de** l'école. |

## 4. Les verbes pronominaux (réfléchis) — reflexive Verben

Reflexive Verben brauchen ein **Reflexivpronomen**, das mit dem Subjekt übereinstimmt und **vor dem konjugierten Verb** steht.

| | se lever (aufstehen) |
|---|---|
| je | **me** lève |
| tu | **te** lèves |
| il/elle/on | **se** lève |
| nous | **nous** levons |
| vous | **vous** levez |
| ils/elles | **se** lèvent |

**Négation:** Je **ne me** lève **pas** tôt. (ne...pas umschliesst Reflexivpronomen + Verb)

> Merke: Im **passé composé** werden alle reflexiven Verben immer mit **être** gebildet, und das Partizip stimmt in der Regel mit dem Subjekt überein: *Elle s'est **levée**. Ils se sont **levés**.*
