# Le futur simple et le conditionnel présent

**Fach:** Französisch | **Klasse:** 4Wa

> ✅ Aus deinen echten OneNote-Notizen (Jahr 4) übernommen und aufbereitet.

## 1. Le futur simple — Bildung

### Regel A: Verben auf -er, -ir
Infinitiv + Endung **-ai, -as, -a, -ons, -ez, -ont**

| | porter | finir |
|---|---|---|
| je | porter**ai** | finir**ai** |
| tu | porter**as** | finir**as** |
| il/elle/on | porter**a** | finir**a** |
| nous | porter**ons** | finir**ons** |
| vous | porter**ez** | finir**ez** |
| ils/elles | porter**ont** | finir**ont** |

### Regel B: Verben auf -dre, -re
Das **-e** des Infinitivs fällt weg, dann dieselben Endungen.

- attendre → j'**attendrai**, tu attendras, il attendra, nous attendrons...
- mettre → je **mettrai**, tu mettras, il mettra, nous mettrons...

### Regel C: Verben mit Akzenten (Stammveränderung im ganzen Futur)
| Verb | Futur (je) |
|---|---|
| acheter | j'**achèterai** |
| peser | je **pèserai** |
| espérer | j'**espérerai** |
| préférer | je **préférerai** |
| se lever | je me **lèverai** |
| se promener | je me **promènerai** |
| s'asseoir | je m'**assiérai** (auch: je m'assoirai / je m'asseyerai, ältere Formen) |

> Achtung Prüfung: Bei *é*-Verben (espérer, préférer) bleibt der Akzent **é** im ganzen Futur erhalten (j'espérerai), bei *e*-Verben (acheter, se lever) wird aus dem stummen *e* ein **è** (j'achèterai).

### Regel D: Unregelmässige Stämme (Stamm ändert sich, Endungen bleiben gleich)

| Verb | Futur (je) | Verb | Futur (je) |
|---|---|---|---|
| être | je **serai** | mourir | je **mourrai** |
| avoir | j'**aurai** | payer | je **paierai** / je **payerai** |
| aller | j'**irai** | placer | je **placerai** |
| apercevoir | j'**apercevrai** | pleuvoir | il **pleuvra** |
| appeler | j'**appellerai** | pouvoir | je **pourrai** |
| appuyer | j'**appuierai** | prévoir | je **prévoirai** |
| boire | je **boirai** | recevoir | je **recevrai** |
| connaître | je **connaîtrai** | savoir | je **saurai** |
| courir | je **courrai** | tenir | je **tiendrai** |
| devenir | je **deviendrai** | valoir (mieux) | il **vaudra** (mieux) |
| devoir | je **devrai** | venir | je **viendrai** |
| dire | je **dirai** | voir | je **verrai** |
| employer | j'**emploierai** | vouloir | je **voudrai** |
| envoyer | j'**enverrai** | | |
| faire | je **ferai** | | |
| falloir | il **faudra** | | |
| jeter | je **jetterai** | | |

> Merke: Vor **j'irai / j'irais** entfällt das Pronominaladverb **y** (nicht: *j'y irai* → richtig einfach *j'irai*, wenn "y" schon im Kontext klar ist).
> Beispiel: *Tu iras à Vienne? – Oui, j'irai.* / *Tu irais au Portugal? – Oui, j'irais, si j'avais l'argent nécessaire.*

## 2. Gebrauch des Futurs

**a) für zukünftige Handlungen, Annahmen:**
- Demain nous **irons** au ciné.
- Elle **arrivera** certainement.
- Quand est-ce que nous **aurons** le plaisir de vous connaître?

**b) nach Verben wie espérer (hoffen), promettre (versprechen), jurer (schwören)**, wenn sie in die Zukunft weisen:
- Nous espérons qu'il **fera** beau temps demain.
- Je te jure que je ne le **ferai** plus jamais.
- Il me promet qu'il ne **mentira** plus.

**c) für Befehle und höfliche Bitten:**
- Vous **fermerez** la porte!
- Vous **ferez** vos devoirs plus sérieusement!
- Il **vaudra** mieux fermer la fenêtre avant de partir. *(Es wird besser sein...)*

## 3. Le conditionnel présent — Bildung

Infinitiv (gleicher Stamm wie im Futur) + Endungen des **imparfait**: **-ais, -ais, -ait, -ions, -iez, -aient**

| | être | avoir | faire | aller |
|---|---|---|---|---|
| je/j' | serais | aurais | ferais | irais |
| tu | serais | aurais | ferais | irais |
| il/elle | serait | aurait | ferait | irait |
| nous | serions | aurions | ferions | irions |
| vous | seriez | auriez | feriez | iriez |
| ils/elles | seraient | auraient | feraient | iraient |

Verben mit Akzenten und die unregelmässigen Stämme (acheter → j'achèterais, être → je serais, avoir → j'aurais, aller → j'irais, apercevoir → j'apercevrais, appeler → j'appellerais, devoir → je devrais, faire → je ferais, falloir → il faudrait, pleuvoir → il pleuvrait, pouvoir → je pourrais, savoir → je saurais, venir → je viendrais, voir → je verrais, vouloir → je voudrais, usw.) folgen **exakt demselben unregelmässigen Stamm** wie beim futur simple — nur die Endungen sind anders.

> Merke: Futur simple und Conditionnel présent teilen sich **denselben Verbstamm** (z. B. *ir-* bei aller, *fer-* bei faire, *aur-* bei avoir) — nur die Endungen unterscheiden sie: Futur = Präsens-Endungen von avoir (-ai, -as, -a...), Conditionnel = Imparfait-Endungen (-ais, -ais, -ait...).

## 4. Gebrauch des Konditionals

Das Konditional drückt aus: eine **Möglichkeit**, einen **Wunsch**, eine **Bitte**, einen **Vorschlag**, eine **Vermutung**, einen **Zweifel**, eine **höfliche Frage** oder **Entrüstung/Empörung**.

Als Zeit wird es verwendet:
- in der **indirekten Rede** für das Futur, von der Vergangenheit aus gesehen
- in **si-Sätzen** (siehe eigenes Merkblatt *La phrase conditionnelle avec "si"*)

**Beispiele:**
- **Pourrais**-tu m'aider?
- On **pourrait** aller au théâtre.
- À sa place je n'**irais** pas à Vienne ce week-end.
- Il **serait** peut-être malade.
- Je **voudrais** bien vous rendre visite.
- Au cas où il **pleuvrait**, fermez toutes les fenêtres.

> Achtung Prüfung: Verwechsle nicht **futur simple** (*j'irai* = ich werde gehen, sichere Zukunft) mit **conditionnel présent** (*j'irais* = ich würde gehen, unter einer Bedingung). Die Endung -ai vs. -ais ist beim Schreiben der einzige Unterschied bei vielen Verben — genau hinhören/hinschauen!
