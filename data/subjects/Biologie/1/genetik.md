# Genetik — Grundlagen

## DNA und Gene
- **DNA** (Desoxyribonukleinsäure) = Träger der Erbinformation
- Besteht aus **4 Basen**: Adenin (A), Thymin (T), Guanin (G), Cytosin (C)
- Komplementäre Basenpaarung: A–T, G–C
- **Gen** = Abschnitt der DNA, der ein Protein codiert

## Chromosomen
- Mensch: **46 Chromosomen** (23 Paare)
- 22 Autosomen-Paare + 1 Geschlechtschromosomenpaar (XX = weiblich, XY = männlich)
- **Homologe Chromosomen** = gleiche Gene, von Vater und Mutter je eines

## Grundbegriffe
| Begriff | Bedeutung |
|---------|-----------|
| **Genotyp** | genetische Ausstattung (z.B. Aa) |
| **Phänotyp** | sichtbares Merkmal (z.B. braune Augen) |
| **Allele** | verschiedene Ausprägungen eines Gens |
| **dominant** | setzt sich gegenüber dem rezessiven Allel durch |
| **rezessiv** | wird nur sichtbar wenn homozygot (aa) |
| **homozygot** | beide Allele gleich (AA oder aa) |
| **heterozygot** | verschiedene Allele (Aa) |

## Mendel'sche Gesetze

### 1. Uniformitätsgesetz
Kreuzt man zwei reinerbige Eltern → alle F₁-Nachkommen gleich (Aa = heterozygot)

### 2. Spaltungsgesetz (F₁ × F₁)
Verhältnis in F₂: **3 : 1** (dominant : rezessiv)

Kreuzungsschema Aa × Aa:
|   | A  | a  |
|---|----|----|
| **A** | AA | Aa |
| **a** | Aa | aa |
→ AA : Aa : aa = 1 : 2 : 1 (Genotyp)
→ dominant : rezessiv = 3 : 1 (Phänotyp)

## Mutationen
- **Genmutation**: Änderung in der Basensequenz
- **Chromosomenmutation**: Struktur/Anzahl der Chromosomen verändert
- Ursachen: UV-Strahlung, Chemikalien, Kopierfehler
