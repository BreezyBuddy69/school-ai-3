# Photosynthese

## Grundprinzip
Pflanzen wandeln **Lichtenergie** in **chemische Energie** (Zucker) um.

**Gesamtgleichung:**
6 CO₂ + 6 H₂O + Lichtenergie → C₆H₁₂O₆ + 6 O₂

## Ort der Photosynthese
Findet in den **Chloroplasten** statt (enthalten das grüne Pigment **Chlorophyll**).

## Zwei Phasen

### 1. Lichtreaktion (in den Thylakoidmembranen)
- Licht wird von Chlorophyll absorbiert
- Wasser wird gespalten: **Fotospaltung** → O₂ wird freigesetzt
- **ATP** und **NADPH** werden gebildet (Energieträger)

### 2. Dunkelreaktion / Calvin-Zyklus (im Stroma)
- CO₂ wird mit ATP und NADPH "fixiert"
- Glucose (C₆H₁₂O₆) wird aufgebaut

## Einflussfaktoren auf die Photosyntheserate
| Faktor | Wirkung |
|--------|---------|
| Lichtintensität | ↑ Licht → ↑ Photosynthese (bis Sättigung) |
| CO₂-Konzentration | ↑ CO₂ → ↑ Rate |
| Temperatur | Optimum ~25°C, zu hoch → Enzyme denaturieren |
| Wasser | Mangel → Stomata schliessen → weniger CO₂ |

## Vergleich: Photosynthese vs. Zellatmung
| | Photosynthese | Zellatmung |
|---|---|---|
| Ort | Chloroplasten | Mitochondrien |
| Edukte | CO₂ + H₂O | Glucose + O₂ |
| Produkte | Glucose + O₂ | CO₂ + H₂O + ATP |
| Energieumwandlung | Licht → chemisch | chemisch → ATP |
