## Vergleich: Nervensystem vs. Hormonsystem

| | Nervensystem | Hormonsystem |
|---|---|---|
| Datenleitung über | Nerven | Blutgefässe |
| Informationsträger | elektrische Impulse | Hormone (chemische Botenstoffe) |
| Empfänger/Transporteur | Nerv | Blut/Blutbahn |
| Geschwindigkeit der Informationsweitergabe | sehr schnell | langsamer |
| Zeitdauer der Wirksamkeit | kurz (ms) | für längere Zeit wirksam |
| Zahl der gleichzeitig weitergeleiteten Infos | 1 pro Nerv | mehrere in Depots |
| Zielzellen | Muskel-/Drüsenzellen mit Nerv | Zellen mit passendem Rezeptor |

> Merke: Das Hormonsystem ist **langsamer**, wirkt aber **länger anhaltend** als das Nervensystem — die beiden Systeme ergänzen sich.

## Die Hierarchie des Hormonsystems

$$\text{Grosshirn} \to \text{Hypothalamus} \to \text{Hypophyse} \to \text{Hormondrüse (z. B. Nebenniere)} \to \text{Zielzelle}$$

## Regelkreis-Fachbegriffe (allgemein)

Ein biologischer Regelkreis funktioniert wie ein technisches Regelsystem — folgende Begriffe sind zentral und prüfungsrelevant:

| Begriff | Bedeutung |
|---|---|
| **Führungsglied** | gibt den Sollwert vor und "leitet" den Regelkreis |
| **Sollwert** | der Zielwert, den das System erreichen/halten soll |
| **Regler** | reagiert auf Abweichungen vom Sollwert und steuert die Stellgrösse |
| **Stellwert** | die vom Regler erzeugte Grösse, die auf das Stellglied wirkt |
| **Stellglied** | das Element, das die Stellgrösse verändert, um den Sollwert zu erreichen |
| **Stellgrösse** | die physikalische/chemische Grösse, die durch das Stellglied verändert wird |
| **Messglied** | misst die aktuelle Istgrösse und gibt Rückmeldung |
| **Regelgrösse** (Istwert) | die tatsächlich vom System geregelte Grösse |
| **Störgrösse** | eine äussere Grösse, die das System beeinflusst und den Sollwert-Ist-Abgleich stört |

**Positive vs. negative Rückkopplung:**
- **Positive Rückkopplung:** je mehr, desto mehr (verstärkend)
- **Negative Rückkopplung:** je mehr, desto weniger (ausgleichend) — die meisten Körper-Regelkreise (z. B. Blutzucker, Hormonspiegel) funktionieren so

## Beispiel: Der Blutzucker-Regelkreis (Begriffe zugeordnet)

| Regelkreis-Begriff | Konkret beim Blutzucker |
|---|---|
| Führungsglied | Hypothalamus — gibt vor, welcher Blutzuckerwert ideal ist (~100 mg/dL) |
| Sollwert | der gewünschte Blutzuckerspiegel |
| Regler | Bauchspeicheldrüse — reagiert auf den Istwert |
| Stellwert | Insulin bzw. Glukagon |
| Stellglied | Leber/Muskeln |
| Stellgrösse | Glykogen (Auf-/Abbau) |
| Messglied | Inselzellen der Bauchspeicheldrüse |
| Regelgrösse | der aktuelle Blutzuckerspiegel |
| Störgrösse | Nahrungsaufnahme (Zucker/Essen) |

> Achtung Prüfung: Bei Regelkreis-Aufgaben immer zuerst **Führungsglied, Sollwert und Regler** identifizieren — von dort aus lassen sich Stellglied/Stellgrösse und Messglied/Regelgrösse logisch ableiten.
