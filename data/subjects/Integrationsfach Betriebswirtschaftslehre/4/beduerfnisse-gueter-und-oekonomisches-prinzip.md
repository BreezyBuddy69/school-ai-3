## Bedürfnisse — Ausgangspunkt allen Wirtschaftens

**Bedürfnis:** das Gefühl eines Mangels, verbunden mit dem Wunsch, diesen zu beseitigen.

### Bedürfnispyramide nach Maslow
| Stufe | Beispiel |
|---|---|
| Existenzbedürfnisse | Nahrung, Schlaf, Wohnung |
| Sicherheitsbedürfnisse | Arbeitsplatz, Versicherung |
| Soziale Bedürfnisse | Freundschaft, Zugehörigkeit |
| Individualbedürfnisse | Anerkennung, Status |
| Selbstverwirklichung | persönliche Entfaltung |

> Merke: Bedürfnisse sind **unbegrenzt** — die zur Verfügung stehenden Mittel (Güter), um sie zu befriedigen, sind **begrenzt**. Aus dieser Spannung entsteht das wirtschaftliche Handeln (behandelt am Beispiel Robinson Crusoe im Unterricht).

## Güter — Mittel zur Bedürfnisbefriedigung

**Gut:** jedes Mittel, das geeignet ist, ein Bedürfnis zu befriedigen.

| Kriterium | Arten |
|---|---|
| Verfügbarkeit | **freie Güter** (unbegrenzt, z. B. Luft) vs. **wirtschaftliche/knappe Güter** (begrenzt, haben einen Preis) |
| Beschaffenheit | **materielle Güter** (Sachgüter) vs. **immaterielle Güter** (Dienstleistungen, Rechte) |
| Verwendungszweck | **Konsumgüter** vs. **Produktionsgüter** |
| Nutzungsdauer | **Gebrauchsgüter** (mehrfach nutzbar) vs. **Verbrauchsgüter** (einmalig nutzbar) |

> Achtung Prüfung: Nur **knappe/wirtschaftliche Güter** sind Gegenstand der Wirtschaft — freie Güter haben keinen Preis, solange sie nicht knapp sind.

## Wertschöpfung

**Wertschöpfung:** die Transformation von vorhandenen Gütern in Güter mit höherem monetären Wert — das Ziel jeder produktiven Tätigkeit. Sie bemisst die Differenz zwischen Gesamtleistung (Output) und den verbrauchten Vorleistungen (Input).

$$\text{Wertschöpfung} = \text{Gesamtleistung} - \text{Vorleistung}$$

```
Beispiel Brauerei:
Rohstoffe (Hopfen, Weizen, Malz, Hefe, Fass) zugekauft für 25 CHF
Verkaufspreis pro Fass Bier: 45 CHF
Wertschöpfung je Fass = 45 − 25 = 20 CHF
```

> Merke: Die Wertschöpfung gibt Auskunft über die wirtschaftliche Leistungsfähigkeit und Produktivität einzelner Prozesse eines Unternehmens oder ganzer Volkswirtschaften — ökonomisches Handeln strebt danach, die Wertschöpfung zu maximieren.

## Das ökonomische Prinzip

Weil Güter knapp sind, muss mit ihnen haushälterisch umgegangen werden.

### Minimalprinzip
Ein gegebenes Ziel (Output) mit möglichst geringem Mitteleinsatz (Input) erreichen.
```
Output fix, gegeben → Input minimieren
```

### Maximalprinzip
Mit gegebenen Mitteln (Input) den grösstmöglichen Nutzen/Ertrag (Output) erzielen.
```
Input fix, gegeben → Output maximieren
```

### Extremumprinzip (Optimumprinzip)
Sowohl Input als auch Output werden verändert, um das bestmögliche Verhältnis zu erreichen.

| Prinzip | Input | Output |
|---|---|---|
| Minimalprinzip | variabel (minimieren) | fix |
| Maximalprinzip | fix | variabel (maximieren) |
| Extremumprinzip | variabel | variabel |

## Produktivität und Wirtschaftlichkeit (reales Prüfungsbeispiel)

```
Ein Dosenhersteller fabriziert aus 50 kg Blech 300 Dosen, Ausschuss 10%.
Zeitaufwand einer Maschine: 2 Sekunden/Dose.

Produktivität des Blecheinsatzes = Output (Dosen) / Input (Blech)
Produktivität des Maschineneinsatzes = Output (Dosen) / Input (Zeit)

Wird der Ausschuss auf 4% reduziert (aber der Zeitaufwand steigt um 0.2 Sek/Dose),
verändern sich beide Produktivitäten — man muss abwägen, welche Variante bei
gegebenen Kosten (1 kg Blech = 1.20 CHF, Verkaufspreis/Dose = 30 Rp.,
Maschinenstunde = 90 CHF) die höhere Wirtschaftlichkeit bringt.
```

> Merke: Das ökonomische Prinzip ist eine **formale Regel**, keine moralische Aussage — es sagt nichts darüber, *was* produziert werden soll, nur *wie effizient* mit den knappen Mitteln umgegangen wird.
