## Unternehmensziele

Unternehmen verfolgen nie nur ein einziges Ziel. Man unterscheidet üblicherweise:

| Zielart | Beispiel |
|---|---|
| **Sachziele** | *was* das Unternehmen tut (Leistungsziele, z. B. "wir produzieren Möbel") |
| **Formalziele** | *wie erfolgreich* das Unternehmen dabei ist (Erfolgsziele, z. B. Gewinn, Rentabilität, Marktanteil) |
| **Ökonomische Ziele** | Gewinn, Wachstum, Marktanteil, Rentabilität |
| **Soziale Ziele** | gute Arbeitsbedingungen, Ausbildung, Arbeitsplatzsicherheit |
| **Ökologische Ziele** | Ressourcenschonung, Umweltschutz, CO₂-Reduktion |

## Beziehungen zwischen Zielen

Ziele eines Unternehmens stehen in unterschiedlichen Beziehungen zueinander:

### Zielharmonie (komplementäre Ziele)
Das Erreichen des einen Ziels **fördert** das andere.
```
Beispiel: Höhere Mitarbeiterzufriedenheit → weniger Fehler → höhere Produktqualität
```

### Zielneutralität (indifferente Ziele)
Die Ziele **beeinflussen sich nicht** gegenseitig.
```
Beispiel: Die Wahl der Bürofarbe hat keinen Einfluss auf den Umsatz.
```

### Zielkonflikt (konkurrierende Ziele)
Das Erreichen des einen Ziels **erschwert** das andere.
```
Beispiel: Löhne erhöhen (soziales Ziel) ↔ Gewinn maximieren (ökonomisches Ziel)
Beispiel: In neue Filteranlagen investieren (ökologisches Ziel) ↔ Kosten senken (ökonomisches Ziel)
```

| Beziehung | Wirkung von Ziel A auf Ziel B |
|---|---|
| Zielharmonie | positiv — A fördert B |
| Zielneutralität | keine — A hat keinen Effekt auf B |
| Zielkonflikt | negativ — A erschwert B |

> Merke: In der Praxis überwiegen oft **Zielkonflikte** — deshalb muss die Unternehmensführung ständig **Prioritäten setzen und abwägen** (Zielhierarchie).

## Zielhierarchie

Damit Ziele im Alltag umsetzbar werden, werden sie konkretisiert:

```
Vision/Leitbild (sehr abstrakt, langfristig)
        ↓
Oberziele / strategische Ziele (z. B. "Marktführer in der Schweiz werden")
        ↓
Teilziele / operative Ziele (z. B. "Umsatz in Region X um 10% steigern")
        ↓
Massnahmen (konkrete Handlungen, z. B. "neue Filiale eröffnen")
```

> Achtung Prüfung: Wenn du in einer Aufgabe zwei Ziele eines Unternehmens vorgelegt bekommst, musst du **begründen können**, ob eine Zielharmonie, Zielneutralität oder ein Zielkonflikt vorliegt — nicht nur die Beziehung benennen.
