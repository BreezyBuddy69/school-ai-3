## Unternehmensziele

Unternehmen verfolgen nie nur ein einziges Ziel. Man unterscheidet üblicherweise:

| Zielart | Beispiel |
|---|---|
| **Sachziele** | *was* das Unternehmen tut (z. B. "wir produzieren Möbel") |
| **Formalziele** | *wie erfolgreich* das Unternehmen dabei ist (Gewinn, Rentabilität, Marktanteil) |
| **Ökonomische Ziele** | Gewinn, Wachstum, Marktanteil, Rentabilität |
| **Soziale Ziele** | gute Arbeitsbedingungen, Ausbildung, Arbeitsplatzsicherheit |
| **Ökologische Ziele** | Ressourcenschonung, Umweltschutz, CO₂-Reduktion |

## Beziehungen zwischen Zielen

### Zielharmonie (komplementäre Ziele)
Das Erreichen des einen Ziels **fördert** das andere.
```
Beispiel: Höhere Mitarbeiterzufriedenheit → weniger Fehler → höhere Produktqualität
```

### Zielneutralität (indifferente Ziele)
Die Ziele beeinflussen sich nicht gegenseitig.

### Zielkonflikt (konkurrierende Ziele)
Das Erreichen des einen Ziels **erschwert** das andere. Ein Zielkonflikt besteht für eine Unternehmung dann, wenn die Lösung eines unternehmerischen Problems (z. B. Produktion ohne umweltschädigende Nebenwirkungen) die Erreichung eines andern Ziels (z. B. aus Konkurrenzgründen möglichst billige Produktion) **verunmöglicht oder gar behindert**.

```
Reales Übungsbeispiel (Lückentext, sinngemäss ergänzt):
"Die gleichzeitige Realisierung hoher Ansprüche im Umweltschutzbereich und
eines aus Konkurrenzgründen möglichst tief anzusetzenden Verkaufspreises
führt in einer Unternehmung fast zwangsläufig zu einem Zielkonflikt."
```

| Beziehung | Wirkung von Ziel A auf Ziel B |
|---|---|
| Zielharmonie | positiv — A fördert B |
| Zielneutralität | keine — A hat keinen Effekt auf B |
| Zielkonflikt | negativ — A erschwert B |

> Merke: In der Praxis überwiegen oft **Zielkonflikte** — deshalb muss die Unternehmensführung ständig Prioritäten setzen und abwägen (Zielhierarchie).

## Netzwerkdarstellung von Zielbeziehungen (reales Praxisbeispiel)

Beziehungen zwischen Zielelementen werden im Unterricht mit **Pfeilen in einem Netzwerk** dargestellt:

```
Beispiel: Snowboard-Unternehmung senkt Verkaufspreise um 10%, erwartet dadurch
15% mehr verkaufte Snowboards. Das Verkaufspersonal ist an der Stückzahl beteiligt.

gleichgerichtete Beziehung (+): je grösser ... desto grösser ... / je kleiner ... desto kleiner ...
entgegengerichtete Beziehung (-): je kleiner ... desto grösser ... / je weniger ... desto mehr ...
```

## Zielhierarchie

```
Vision/Leitbild (sehr abstrakt, langfristig)
        ↓
Oberziele / strategische Ziele (z. B. "Marktführer in der Schweiz werden")
        ↓
Teilziele / operative Ziele (z. B. "Umsatz in Region X um 10% steigern")
        ↓
Massnahmen (konkrete Handlungen, z. B. "neue Filiale eröffnen")
```

> Achtung Prüfung: Wenn du zwei Ziele eines Unternehmens vorgelegt bekommst, musst du **begründen können**, ob eine Zielharmonie, Zielneutralität oder ein Zielkonflikt vorliegt — nicht nur die Beziehung benennen. Konkrete Anspruchsgruppen-Beispiele siehe `anspruchsgruppen-des-unternehmens.md`.
