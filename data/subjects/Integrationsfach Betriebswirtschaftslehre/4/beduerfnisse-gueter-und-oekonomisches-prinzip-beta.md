## Bedürfnisse — Ausgangspunkt allen Wirtschaftens

**Bedürfnis:** das Gefühl eines Mangels, verbunden mit dem Wunsch, diesen zu beseitigen.

### Bedürfnispyramide nach Maslow (Einordnung)
| Stufe | Beispiel |
|---|---|
| Existenzbedürfnisse | Nahrung, Schlaf, Wohnung |
| Sicherheitsbedürfnisse | Arbeitsplatz, Versicherung |
| Soziale Bedürfnisse | Freundschaft, Zugehörigkeit |
| Individualbedürfnisse | Anerkennung, Status |
| Selbstverwirklichung | persönliche Entfaltung |

### Weitere Einteilung
- **Existenzbedürfnisse:** lebensnotwendig (Nahrung, Kleidung, Wohnung)
- **Kulturbedürfnisse:** nicht überlebensnotwendig, aber üblich (Bildung, Kultur, Reisen)
- **Luxusbedürfnisse:** individuell, oft statusgetrieben (Villa, Sportwagen)

> Merke: Bedürfnisse sind **unbegrenzt** — die zur Verfügung stehenden Mittel (Güter), um sie zu befriedigen, sind **begrenzt**. Genau aus dieser Spannung entsteht das wirtschaftliche Handeln.

## Güter — Mittel zur Bedürfnisbefriedigung

**Gut:** jedes Mittel, das geeignet ist, ein Bedürfnis zu befriedigen.

### Einteilung der Güter
| Kriterium | Arten |
|---|---|
| Verfügbarkeit | **freie Güter** (unbegrenzt vorhanden, z. B. Luft) vs. **wirtschaftliche/knappe Güter** (begrenzt, haben einen Preis) |
| Beschaffenheit | **materielle Güter** (Sachgüter, z. B. ein Auto) vs. **immaterielle Güter** (Dienstleistungen, Rechte) |
| Verwendungszweck | **Konsumgüter** (für Endverbraucher) vs. **Produktionsgüter** (für die Herstellung weiterer Güter) |
| Nutzungsdauer | **Gebrauchsgüter** (mehrfach nutzbar, z. B. Maschine) vs. **Verbrauchsgüter** (einmalig nutzbar, z. B. Rohstoff) |

> Achtung Prüfung: Nur **knappe/wirtschaftliche Güter** sind Gegenstand der Wirtschaft — freie Güter haben keinen Preis, weil sie nicht knapp sind (solange sie es bleiben).

## Das ökonomische Prinzip

Weil Güter knapp sind, muss mit ihnen **haushälterisch** umgegangen werden — das nennt man das **ökonomische Prinzip** (Wirtschaftlichkeitsprinzip).

### Minimalprinzip
Ein gegebenes Ziel (Output) mit **möglichst geringem Mitteleinsatz** (Input) erreichen.

```
Output fix, gegeben → Input minimieren
Beispiel: Für 100 produzierte Stühle möglichst wenig Material/Zeit einsetzen
```

### Maximalprinzip
Mit gegebenen Mitteln (Input) den **grösstmöglichen Nutzen/Ertrag** (Output) erzielen.

```
Input fix, gegeben → Output maximieren
Beispiel: Mit einem Budget von 10'000 CHF möglichst viele/gute Stühle produzieren
```

### Extremumprinzip (Optimumprinzip)
Sowohl Input als auch Output werden verändert, um das **bestmögliche Verhältnis** zwischen beiden zu erreichen — weder Mittel noch Ziel sind fix vorgegeben.

| Prinzip | Input | Output |
|---|---|---|
| Minimalprinzip | variabel (minimieren) | fix |
| Maximalprinzip | fix | variabel (maximieren) |
| Extremumprinzip | variabel | variabel |

> Merke: Das ökonomische Prinzip ist eine **formale Regel**, keine moralische Aussage — es sagt nichts darüber, *was* produziert werden soll, nur *wie effizient* mit den knappen Mitteln umgegangen wird.
