# Lineare Funktionen

## Definition
Eine lineare Funktion hat die Form **f(x) = mx + b**, wobei:
- **m** = Steigung (wie steil die Gerade ist)
- **b** = y-Achsenabschnitt (wo die Gerade die y-Achse schneidet)

## Steigung berechnen
$$m = \frac{y_2 - y_1}{x_2 - x_1} = \frac{\Delta y}{\Delta x}$$

**Beispiel:** Punkte A(1|3) und B(4|9)
$$m = \frac{9-3}{4-1} = \frac{6}{3} = 2$$

## Typen
| Steigung | Beschreibung | Beispiel |
|----------|-------------|---------|
| m > 0 | steigend | f(x) = 2x + 1 |
| m < 0 | fallend | f(x) = -x + 5 |
| m = 0 | waagrecht | f(x) = 3 |

## Schnittpunkte
- **x-Achse:** f(x) = 0 setzen, nach x auflösen
- **y-Achse:** x = 0 einsetzen → Ergebnis ist b

## Zwei Geraden
- **Parallel:** gleiche Steigung m, verschiedenes b
- **Senkrecht:** m₁ · m₂ = -1
- **Schnittpunkt:** Gleichung gleichsetzen

## Aufgabe-Typen
1. Funktionsgleichung aus zwei Punkten bestimmen
2. Schnittpunkt zweier Geraden finden
3. Parallele/senkrechte Gerade konstruieren

## Merkhilfe
> **"m wie Mühe = Steigung"** — steil = grosse Zahl
