# Gleichungen lösen

## Lineare Gleichungen
**Ziel:** x isolieren — alles was nicht x ist auf die andere Seite.

**Regel:** Was du auf einer Seite machst, machst du auf beiden!

### Vorgehen
1. Klammern auflösen
2. Gleiche Terme zusammenfassen
3. x auf eine Seite bringen
4. Durch Koeffizient teilen

**Beispiel:**
```
3x + 7 = 22
3x = 22 - 7
3x = 15
x = 5
```

## Quadratische Gleichungen
Form: **ax² + bx + c = 0**

### Lösungsformel (pq-Formel)
Bei x² + px + q = 0:
$$x_{1,2} = -\frac{p}{2} \pm \sqrt{\left(\frac{p}{2}\right)^2 - q}$$

### Diskriminante D = (p/2)² - q
| D | Anzahl Lösungen |
|---|----------------|
| D > 0 | 2 Lösungen |
| D = 0 | 1 Lösung (Doppellösung) |
| D < 0 | keine reelle Lösung |

### Satz von Vieta
Für x² + px + q = 0 gilt:
- x₁ + x₂ = -p
- x₁ · x₂ = q

## Bruchgleichungen
1. Nenner ausschliessen (Nenner ≠ 0)
2. Auf gemeinsamen Nenner bringen
3. Zähler gleichsetzen
4. Probe machen!
