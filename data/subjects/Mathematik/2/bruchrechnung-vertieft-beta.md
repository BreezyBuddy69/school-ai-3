## Rückblick: Grundbegriffe
$$\underbrace{3}_{\text{Zähler}} \Big/ \underbrace{4}_{\text{Nenner}}$$

**Erweitern:** Zähler und Nenner mit derselben Zahl multiplizieren (Wert bleibt gleich).
**Kürzen:** Zähler und Nenner durch denselben Teiler dividieren (Wert bleibt gleich).

![Bennett-Bruchbalken zur Veranschaulichung verschiedener Brüche](https://upload.wikimedia.org/wikipedia/commons/c/cb/Bennett_fraction_bars_complete_deck.svg)

## Addition und Subtraktion
**Regel:** Nur Brüche mit **gleichem Nenner** können direkt addiert/subtrahiert werden — sonst zuerst auf den **Hauptnenner** (kgV der Nenner) erweitern.

**Beispiel:**
```
1/4 + 1/6
kgV(4,6) = 12
= 3/12 + 2/12 = 5/12
```

## Multiplikation
**Regel:** Zähler mal Zähler, Nenner mal Nenner. Wenn möglich **vor** dem Ausrechnen kürzen.
$$\frac{a}{b} \cdot \frac{c}{d} = \frac{a \cdot c}{b \cdot d}$$

**Beispiel:**
```
2/3 · 9/10 = (2·9)/(3·10) = 18/30 = 3/5
```

## Division
**Regel:** Geteilt durch einen Bruch = mal dessen **Kehrwert** (Zähler und Nenner vertauschen).
$$\frac{a}{b} : \frac{c}{d} = \frac{a}{b} \cdot \frac{d}{c}$$

**Beispiel:**
```
3/4 : 2/5 = 3/4 · 5/2 = 15/8
```

## Gemischte Zahlen
| Umwandlung | Vorgehen | Beispiel |
|---|---|---|
| Gemischt → unechter Bruch | Ganze Zahl · Nenner + Zähler, gleicher Nenner | 2¾ = (2·4+3)/4 = 11/4 |
| Unechter Bruch → gemischt | Zähler durch Nenner dividieren, Rest bleibt Zähler | 11/4 = 2 Rest 3 → 2¾ |

> Merke: Bei Addition/Subtraktion **gemischter Zahlen** entweder zuerst in unechte Brüche umwandeln, oder ganze Zahlen und Bruchteile getrennt rechnen (auf Überträge beim Bruchteil achten!).

## Bruchterme mit Variablen (Vorschau)
Die gleichen Regeln gelten auch, wenn eine Variable im Zähler oder Nenner steht:
```
(2x)/4 = x/2     (gekürzt durch 2)
```

> Achtung Prüfung: Bei der Division wird oft der **Kehrwert des falschen Bruchs** genommen — Kehrwert immer nur vom **zweiten** Bruch (dem Divisor)! Ausserdem: 0 darf nie im Nenner stehen.
