## Was ist ein Term?
Ein **Term** ist ein Rechenausdruck aus Zahlen, Variablen und Rechenzeichen — **ohne** Gleichheitszeichen (sonst wäre es eine Gleichung).

**Beispiele:** `3x + 5`, `2(a - b)`, `x² - 4x + 7`

## Termarten nach Anzahl Summanden
| Bezeichnung | Anzahl Summanden | Beispiel |
|---|---|---|
| **Monom** | 1 | 5x |
| **Binom** | 2 | 3x + 7 |
| **Trinom** | 3 | x² + 2x - 5 |
| **Polynom** | beliebig viele | 2x³ - x² + 4x - 1 |

## Gleichartige Terme zusammenfassen
Nur Terme mit **gleicher Variable und gleichem Exponenten** dürfen addiert/subtrahiert werden.

**Beispiel:**
```
3x + 5x - 2x = 6x
4x² + 2x  →  bleibt so, NICHT zusammenfassbar (verschiedene Exponenten)
```

> Merke: Zahl vor der Variable (der Koeffizient) wird addiert, die Variable (mit Exponent) bleibt unverändert stehen.

## Klammern auflösen
| Klammer-Art | Regel | Beispiel |
|---|---|---|
| **Plusklammer** `+(...)` | Klammer einfach weglassen | 5 + (3x - 2) = 5 + 3x - 2 |
| **Minusklammer** `-(...)` | Jedes Vorzeichen in der Klammer umkehren | 5 - (3x - 2) = 5 - 3x + 2 |

## Ausmultiplizieren (Distributivgesetz)
$$a(b + c) = ab + ac$$

![Illustration des Distributivgesetzes mit Rechtecken](https://upload.wikimedia.org/wikipedia/commons/7/74/Illustration_of_distributive_property_with_rectangles.svg)

Die Fläche des grossen Rechtecks lässt sich auf zwei Arten berechnen: einmal als **a·(b+c)**, einmal als Summe der beiden Teilflächen **a·b + a·c** — beides muss dasselbe Ergebnis liefern.

**Beispiel:**
```
4(2x + 3) = 4·2x + 4·3 = 8x + 12
```

Bei zwei Klammern (jedes mit jedem multiplizieren):
```
(x + 2)(x + 5) = x·x + x·5 + 2·x + 2·5 = x² + 7x + 10
```

## Ausklammern (Faktorisieren)
Der umgekehrte Weg — einen gemeinsamen Faktor vor die Klammer ziehen:
```
8x + 12 = 4(2x + 3)
```

> Achtung Prüfung: Beim Auflösen einer **Minusklammer** wird oft ein Vorzeichen vergessen. `-(x - 3)` ist **nicht** `-x - 3`, sondern `-x + 3`! Jedes einzelne Vorzeichen in der Klammer kippt.

## Vorgehen bei komplexen Termen
1. Klammern auflösen (Punkt- vor Strichrechnung beachten)
2. Potenzen berechnen
3. Malpunkt-Rechnungen ausführen
4. Gleichartige Terme zusammenfassen
