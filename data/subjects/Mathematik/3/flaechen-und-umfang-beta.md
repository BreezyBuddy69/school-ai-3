# Flächeninhalt & Umfang ebener Figuren

## Übersicht der Grundformeln
| Figur | Flächeninhalt $A$ | Umfang $U$ |
|---|---|---|
| Quadrat | $a^2$ | $4a$ |
| Rechteck | $a\cdot b$ | $2(a+b)$ |
| Dreieck | $\dfrac{g\cdot h}{2}$ | $a+b+c$ |
| Parallelogramm | $g\cdot h$ | $2(a+b)$ |
| Trapez | $\dfrac{(a+c)}{2}\cdot h$ | $a+b+c+d$ |
| Kreis | $r^2\pi$ | $2r\pi = d\pi$ |

## Dreieck
```
        /\
       /  \
    h /    \
     /______\
        g
```
$$A = \frac{g\cdot h}{2}$$
$g$ = Grundseite, $h$ = Höhe **senkrecht** zur Grundseite (nicht die schräge Seite!).

**Beispiel:** $g=8\text{ cm}$, $h=5\text{ cm}$
$$A = \frac{8\cdot5}{2} = 20\text{ cm}^2$$

## Parallelogramm
$$A = g\cdot h$$
Ein Parallelogramm lässt sich durch Verschieben eines Dreiecks in ein Rechteck umwandeln — daher **ohne** den Faktor $\tfrac12$.

## Trapez
Ein Trapez hat zwei parallele Seiten $a$ (länger) und $c$ (kürzer):
$$A = \frac{a+c}{2}\cdot h$$

**Herleitung:** Der Mittelwert der beiden parallelen Seiten $\tfrac{a+c}{2}$ entspricht der Grundseite eines flächengleichen Rechtecks mit derselben Höhe $h$.

**Beispiel:** $a=10\text{ cm}$, $c=6\text{ cm}$, $h=4\text{ cm}$
$$A = \frac{10+6}{2}\cdot4 = 8\cdot4 = 32\text{ cm}^2$$

## Kreis
$$A = r^2\pi \qquad\qquad U = 2r\pi = d\pi$$

**Beispiel:** $r=5\text{ cm}$
```
A = 5²·π ≈ 78,54 cm²
U = 2·5·π ≈ 31,42 cm
```

> Achtung Prüfung: $\pi \approx 3{,}14159\ldots$ ist **irrational** — bei Prüfungsaufgaben immer auf die geforderte Anzahl Nachkommastellen runden, nicht während der Rechnung zwischendurch runden.

## Kreissektor (Kreisausschnitt)
Ein Sektor mit Mittelpunktswinkel $\alpha$ ist ein Bruchteil $\dfrac{\alpha}{360°}$ des ganzen Kreises:
$$A_{\text{Sektor}} = \frac{\alpha}{360°}\cdot r^2\pi \qquad\qquad b = \frac{\alpha}{360°}\cdot 2r\pi \; (\text{Bogenlänge})$$

**Beispiel:** $r=6\text{ cm}$, $\alpha=60°$
```
A = 60/360 · 6²π = 1/6 · 36π ≈ 18,85 cm²
```

## Zusammengesetzte Flächen
Viele Aufgaben kombinieren mehrere Grundfiguren. **Vorgehen:**
1. Figur in bekannte Grundfiguren zerlegen (oder ein grösseres Rechteck ergänzen und Teile abziehen)
2. Jede Teilfläche einzeln berechnen
3. Teilflächen addieren (zusammengesetzt) oder subtrahieren (ausgeschnitten)

> Merke: Diese Grundformeln sind die 2D-Basis für die Körperberechnung (Prisma, Pyramide — eigenes Thema) und für die Stereometrie in Jahr 5, wo Grund- und Mantelflächen aus genau diesen ebenen Figuren bestehen.
