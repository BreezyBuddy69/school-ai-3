## Textverarbeitung — Grundbegriffe
Ein **Textverarbeitungsprogramm** (z.B. Word, LibreOffice Writer) dient dem Erstellen, Formatieren und Speichern von Dokumenten.

| Begriff | Bedeutung |
|---|---|
| **Zeichenformatierung** | Schriftart, -grösse, fett/kursiv/unterstrichen |
| **Absatzformatierung** | Ausrichtung (links/zentriert/rechts/Blocksatz), Zeilenabstand, Einzüge |
| **Formatvorlage** | vordefiniertes Set an Formatierungen (z.B. „Überschrift 1"), sorgt für einheitliches Aussehen |
| **Kopf-/Fusszeile** | wiederkehrender Bereich oben/unten auf jeder Seite (z.B. Seitenzahl, Titel) |

> Merke: Formatvorlagen statt manueller Formatierung verwenden — ändert man die Vorlage, passt sich der ganze Text automatisch an.

### Nützliche Funktionen
- **Rechtschreibprüfung**: unterringelt Fehler automatisch
- **Silbentrennung**: verhindert hässliche Lücken im Blocksatz
- **Inhaltsverzeichnis**: wird automatisch aus Überschriften-Formatvorlagen erzeugt
- **Serienbrief**: verbindet eine Vorlage mit einer Liste (z.B. Adressen) zu vielen individuellen Dokumenten

## Präsentationen — Grundbegriffe
Ein **Präsentationsprogramm** (z.B. PowerPoint, LibreOffice Impress) organisiert Inhalte in **Folien (Slides)**.

### Aufbau einer guten Folie
| Prinzip | Erklärung |
|---|---|
| **Wenig Text** | Stichworte statt ganzer Sätze — die sprechende Person füllt die Lücken |
| **Eine Kernaussage pro Folie** | überladene Folien verwirren |
| **Kontrast** | Text muss sich klar vom Hintergrund abheben |
| **Konsistentes Layout** | gleiche Schriftart/Farben auf allen Folien (Folienmaster nutzen) |

> Achtung Prüfung: Der **Folienmaster** (Master Slide) legt das Grunddesign fest — Änderungen dort wirken auf alle Folien gleichzeitig, das ist der grosse Vorteil gegenüber dem manuellen Anpassen jeder einzelnen Folie.

### Medien einbinden
- Bilder, Diagramme, Tabellen, Videos lassen sich einfügen
- **Animationen/Übergänge** sparsam einsetzen — lenken sonst vom Inhalt ab
- Präsentation immer vor dem Vortrag testen (Beamer-Kompatibilität, Schriftgrössen aus der letzten Reihe lesbar)

## Dateiformate
| Format | Programm | Endung |
|---|---|---|
| Text | Word / Writer | .docx / .odt |
| Präsentation | PowerPoint / Impress | .pptx / .odp |
| Portables Dokument | — | .pdf (nicht mehr direkt editierbar, aber auf jedem Gerät gleich dargestellt) |

> Merke: Ein Dokument als **PDF exportieren**, bevor man es weitergibt — so bleibt die Formatierung auf jedem Gerät garantiert erhalten.
