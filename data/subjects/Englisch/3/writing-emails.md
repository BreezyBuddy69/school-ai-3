# Writing an Email (Business/Order-Kontext)

> ✅ Aus deinen echten OneNote-Notizen (Jahr 3) übernommen und aufbereitet.

## Kontext: geschäftliche E-Mails (Bestellungen/Anfragen)

Typisches Prüfungsformat: zwei Firmen tauschen E-Mails zu einer **Bestellung** (order) aus — Anfrage, Angebot, Bestätigung.

**Ablauf einer Bestell-E-Mail-Kette:**
1. Anfrage stellen: *I'd like to place an order for five barrels of oil. Do you give a discount for bulk orders?*
2. Antwort mit Angebot: *We give a 10% discount on orders of five barrels or more. What quantity are you interested in?*
3. Bestellung bestätigen: *Please find attached the order form including our payment details. What is the delivery time?*
4. Lieferbestätigung: *We are dispatching the order this afternoon. Use the tracking number below to track your delivery.*

## Nützlicher Business-Wortschatz

| Begriff | Bedeutung |
|---|---|
| **discount** | Rabatt (weniger bezahlen) |
| **bulk** | grosse Menge/Sammelbestellung |
| **barrel** | Fass (Metallbehälter für Flüssigkeiten) |
| **quantity** | Menge |
| **invoice** | Rechnung (Info über Preis + Zahlungsdetails) |
| **to dispatch** | (eine Bestellung) versenden |
| **to track a delivery** | herausfinden, wo sich eine Lieferung gerade befindet |
| **to supply** | liefern/anbieten |

## Nützliche Redemittel

| Funktion | Redemittel |
|---|---|
| Bestellung aufgeben | I'd like to place an order for … |
| nach Rabatt fragen | Do you give a discount for bulk orders? |
| Anhang erwähnen | Please find attached the order form / the invoice. |
| Lieferzeit erfragen | What is the delivery time? |
| um Kontakt bei Problemen bitten | Please do not hesitate to contact me if you experience any delays. |
| Verzögerung melden | We are dispatching the order this afternoon. |

> Merke: Verb + Nomen-Kombinationen aus der Prüfung: **place an order**, **give a discount**, **track the delivery**, **attach an order form**, **experience any delays**.

## Korrekturzeichen deiner Lehrperson

Diese Abkürzungen markieren Fehlerarten in korrigierten Texten (Aufsätze, E-Mails, Briefe):

| Kürzel | Bedeutung |
|---|---|
| G. | Grammar |
| Voc. | Vocabulary |
| Sp. | Spelling |
| Prep. | Preposition |
| Cap. | Capitalization |
| Exp. | Expression |
| Rep. | Repetition |
| T. | Tense |
| P. | Punctuation |
| Art. | Article |
| WO | Word Order |
| MW | Missing Word |
| Co. | Coherence (Zusammenhang) |
| St. | Style |

> Achtung Prüfung: Diese Korrekturzeichen stehen am Rand korrigierter Texte — wichtig, um die eigenen Fehlermuster zu erkennen (z. B. immer wieder „Art." = Artikelfehler → gezielt Artikel-Regeln wiederholen, siehe Themendatei „Articles").
