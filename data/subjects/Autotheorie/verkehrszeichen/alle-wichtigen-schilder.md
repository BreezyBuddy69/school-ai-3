# Alle wichtigen Verkehrsschilder Schweiz

**Fach:** Autotheorie Schweiz (Kategorie B)
**Thema:** Verkehrszeichen — Vollständige Referenz

---

## Kategorie 1: Gefahrensignale (Dreieck, rot-weiss)

| Signal | Bedeutung | Verhalten |
|--------|-----------|-----------|
| Kurve links | Scharfe Linkskurve | Geschwindigkeit reduzieren |
| Kurve rechts | Scharfe Rechtskurve | Geschwindigkeit reduzieren |
| Doppelkurve links | S-Kurve, zuerst links | Vorsichtig fahren |
| Steiles Gefälle | Starkes Gefälle voraus | Niedrigen Gang, Bremsen schonen |
| Steile Steigung | Starke Steigung | Ggf. Gang wechseln |
| Schleudergefahr | Glatte Fahrbahn | Langsam, kein starkes Bremsen/Lenken |
| Verengte Fahrbahn | Strasse wird enger | Bereit zum Anhalten |
| Lichtzeichenanlage | Ampel voraus | Bereit zum Bremsen |
| Fussgängerübergang | Zebrastreifen voraus | Fussgänger beobachten |
| Kinder | Schule/Spielzone | Sehr langsam, besondere Aufmerksamkeit |
| Velofahrende | Velokreuzung/Velostrecke | Auf Velos achten |
| Tiere (Wild) | Wildwechsel | Dämmerung/Nacht: besonders vorsichtig |
| Tiere (Nutztiere) | Kühe, Schafe, Pferde | Langsam, nicht hupen |
| Bahnübergang mit Schranke | Bewachter BÜ voraus | Bereit zum Anhalten |
| Bahnübergang ohne Schranke | Unbewachter BÜ | Anhalten, Nachschauen |
| Strassenbahn | Tramgleis-Kreuzung | Strassenbahn hat Vortritt |
| Steinschlag | Felsbrocken fallen | Rechts halten, nicht anhalten |
| Schnee/Eis | Wintergefahr | Winterausrüstung prüfen |
| Seitenwind | Starke Böen | Lenken anpassen |
| Unebene Fahrbahn | Schlaglöcher, Buckel | Langsam fahren |
| Arbeitsstelle | Baustelle voraus | Langsam, Richtungsänderungen beachten |

## Kategorie 2: Vorschriftssignale – Verbote (Kreis, rot)

| Signal | Bedeutung |
|--------|-----------|
| Einfahrt verboten | Gegenrichtung / Einbahnstrasse falsche Richtung |
| Motorfahrzeuge verboten | Kein Auto, kein Motorrad |
| Motorräder verboten | Nur Motorräder ausgeschlossen |
| LKW verboten | Über bestimmte Tonnage |
| Busse/Cars verboten | Reisebusse ausgeschlossen |
| Fahrräder verboten | Kein Velofahren |
| Fussgänger verboten | Kein Betreten |
| Überholen verboten | Für alle Motorfahrzeuge |
| Überholen für LKW verboten | Nur LKW betroffen |
| Geschwindigkeit X km/h | Max. Höchstgeschwindigkeit |
| Hupen verboten | Akustische Signale untersagt |
| Halten verboten | Kein Anhalten (gelbe Randlinie = gleichwertig) |
| Parkieren verboten | Kein Parkieren (Halten kurz erlaubt) |
| Wenden verboten | Kein Wenden |

### Ende eines Verbots
- Grauer Hintergrund + Schrägstrich = betreffendes Verbot endet

## Kategorie 3: Vorschriftssignale – Gebote (Kreis, blau)

| Signal | Bedeutung |
|--------|-----------|
| Vorgeschriebene Fahrtrichtung ↑ | Geradeaus fahren |
| Vorgeschriebene Fahrtrichtung → | Rechts fahren |
| Vorgeschriebene Fahrtrichtung ↑→ | Geradeaus oder rechts |
| Kreisel-Pfeil | Im Kreisverkehr fahren |
| Fussgängerweg | Nur für Fussgänger |
| Veloweg | Nur für Fahrräder |
| Velo + Fussgänger | Gemeinsamer Weg |
| Schneeketten | Schneeketten obligatorisch |
| Mindestgeschwindigkeit | Nicht langsamer fahren |

## Kategorie 4: Vortrittsregelnde Signale

| Signal | Form/Farbe | Bedeutung |
|--------|-----------|-----------|
| Vortritt gewähren | Dreieck, weiß-rot | Anderen Vortritt lassen |
| STOP | Achteck, rot | Anhalten + Vortritt gewähren |
| Vortrittsstrasse | Raute, gelb | Du hast Vortritt |
| Ende Vortrittsstrasse | Raute durchgestrichen | Vortrittsrecht endet |
| Vortritt gegenüber Gegenverkehr | Blau/rot-Pfeil | Du hast Vortritt |
| Vortritt dem Gegenverkehr | Rot/blau-Pfeil | Gegenverkehr hat Vortritt |

## Kategorie 5: Hinweissignale (Rechteck, blau/grün)

| Signal | Bedeutung |
|--------|-----------|
| Autobahn (blau) | Autobahn beginnt → 120 km/h |
| Ende Autobahn | Autobahn endet |
| Autostrasse (blau) | 100 km/h, kein Langsamverkehr |
| Hauptstrasse (grün) | Schnellverbindung |
| Parkplatz «P» | Parkieren erlaubt |
| Camping | Campingplatz voraus |
| Tankstelle | Benzin/Diesel/Strom |
| Notfalltelefon | SOS-Station |
| Spital | Notaufnahme, Krankenhaus |
| Zollstation | Grenzübergang |

## Kategorie 6: Zonensignale

| Signal | Geschwindigkeit | Besonderheiten |
|--------|----------------|----------------|

| Ende Tempo 30 Zone | Normal (50/80) | |
| Begegnungszone | 20 km/h | Fussgänger auf ganzer Fläche |
| Ende Begegnungszone | | |
| Wohnstrasse | Schrittgeschwindigkeit | Spielende Kinder |
| Fussgängerzone | Fussverkehr | Autos nur mit Sondererlaubnis |
| Umweltzone | Nur schadstoffarme Fzg | In CH aktuell selten |

## Kategorie 7: Sondersignale Baustellen & Alpenpässe

| Signal | Bedeutung |
|--------|-----------|
| Arbeitsstelle (Dreieck) | Baustelle — Langsam, Arbeiter beachten |
| Temporäre Signale (gelber Hintergrund) | Überschreiben permanente Signale |
| Passhöhe X m | Pass auf X Meter — Wintersperre möglich |
| Pass gesperrt | Durchfahrt nicht möglich |
| Pass offen | Durchfahrt möglich |

> Gelb hinterlegte Signale in Baustellen **ersetzen** die normalen Schilder und haben Vorrang!

|------|-------|-----------|

| Kreis | Rot | Verbot |

| Rechteck | Weiss | Ortsangabe |
